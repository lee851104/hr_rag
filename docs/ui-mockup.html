虛構公司的主管特殊內部覆核使用什麼識別表單？未完成這張表能否定法定請假嗎？

已回答
依 2026-10-19 有效版本
公司流程

特殊內部覆核使用橙色覆核單M-17，記錄待確認事項、承辦角色與處理進度。橙色覆核單M-17只作內部追蹤，不是新增的法定請假要件；主管不能僅因未完成此單就否定法定請假。需要人資協助時，移交必要範圍的資訊。

主管請假審核作業（虛構）・C03 v1 §review・2026-01-01 起
公司流程

申請人填寫假別、起迄日期及必要說明；證明文件是否必要與可請求的範圍，須依適用法令判斷。窗口僅通知需釐清的項目，不要求與請假無關的資料。遇緊急情形先以可行方式通知，再處理後續紀錄；不得因內部表單尚未完成而直接否定法定請假權利。
